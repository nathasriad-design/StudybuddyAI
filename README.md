# StudybuddyAI

An AI-powered study assistant designed to help students summarize notes, generate practice quizzes, and streamline learning.

## Features
- **Note Summarization:** Quick, accurate summaries of your study materials.
- **Quiz Generator:** Automatically creates practice questions based on your notes.
- **Interactive Q&A:** Ask questions and get instant explanations.
